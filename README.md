# Triangle Classifier

A Java application that classifies triangles based on three input side lengths.

## Features
- Validates triangle sides
- Classifies as: Equilateral, Isosceles, or Scalene
- Determines angle type: Acute, Right, or Obtuse

## How to Run
```bash
javac TriangleClassifier.java
java TriangleClassifier
```

## Input
Enter three positive numbers representing triangle sides.

## Output
Triangle type and angle classification.
